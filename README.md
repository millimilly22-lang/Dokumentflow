# DokumentFlow PL

Polish-first Smart Document Business website.

## Local development
```bash
npm install
npm run dev
```
Open: http://localhost:8165

## Render deployment
- Build command: `npm install && npm run build`
- Publish directory: `dist`
- Environment variable: `SITE_URL=https://YOUR-FINAL-DOMAIN`

## Included for Google/public launch
- Polish Privacy Policy
- Terms / Regulamin
- Cookie Policy
- About page
- Contact page
- SEO title and meta description
- canonical URL
- Open Graph metadata
- SoftwareApplication structured data
- sitemap.xml
- robots.txt
- web app manifest
- responsive mobile layout
- Google Search Console verification placeholder

## Before production
Replace placeholder company/contact details, set the final domain, add the exact Search Console verification tag, connect secure authentication/storage/OCR, and add consent management before non-essential analytics or advertising cookies are enabled.
